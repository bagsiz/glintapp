# Glint — Disk Cleaner for Mac

Free, native macOS app for cleaning up disk space, protecting your privacy and checking your Mac's security — plus file recovery for USB sticks and SD cards. Turkish and English UI.

**[⬇︎ Download Glint.dmg](https://github.com/bagsiz/glintapp/releases/latest/download/Glint.dmg)** · **[Website](https://glintmac.com/)** · **[FAQ](https://glintmac.com/#faq)**

- macOS 14 Sonoma or later, Apple Silicon and Intel
- Signed with a Developer ID and notarized by Apple
- Free, no account, no network requests — your files never leave your Mac

Open the DMG and drag **Glint** into **Applications**. For full scans, give it **Full Disk Access** when it asks.

## Features

- **Cleanup:** Smart Clean (caches, logs, developer leftovers, old iOS backups, installers), Large Files, Duplicate Files, Similar Photos
- **Analysis:** Space Map, Disk Health (NVMe SMART)
- **Management:** Applications with leftovers, Startup Items, Maintenance, scheduled Auto Clean with a menu bar indicator
- **Privacy & Security:** Sensitive Files, Photo Locations, Browser Privacy, Security Scan, App Permissions
- **Recovery:** deleted file recovery for FAT/exFAT and other external disks, Quarantine & History with restore

Nothing is lost by accident: caches that apps rebuild are deleted, everything else goes to Quarantine first and can be restored (7 days by default). System folders are protected, and files of running apps such as Docker Desktop are left alone.
