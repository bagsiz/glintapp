How it works

Scan, review, clean. You decide every step.

01

Scan

Pick a tool and press Scan. Glint reads your disk locally and sorts what it finds into clear groups with sizes and dates.

02

Review

Nothing is pre-deleted. Untick anything you want to keep, or show it in Finder before you decide.

03

Clean

Only what you approved is removed. Rebuildable caches go for good; everything else waits in Quarantine.

Changed your mind? Open Quarantine & History and put it back — for 7 days by default, longer if you like.

Safe by design

Built so a cleaner can't hurt your Mac.

These rules are part of the code, not settings you have to get right.

↩︎

Quarantine first

Only caches that apps rebuild by themselves are deleted outright. Everything else is moved to Quarantine, logged in History and restorable.

⛨

Protected folders

System locations like /System, /usr and the keychains, and your top-level folders like Documents, Desktop and ~/Library, can never be deleted.

☁︎

iCloud stays in the cloud

Files that aren't downloaded are never read, so a scan doesn't quietly pull gigabytes from iCloud Drive.

◷

Running apps are left alone

While an app like Docker Desktop is running, its live files are skipped and Glint tells you why.

≡

A memory ceiling

Scans stop at a memory limit you set, so even a huge disk can't bog your Mac down.

⚿

Root work through a signed helper

Admin jobs go through a small helper that only accepts Glint's own signed app and runs a fixed set of operations, never free-form commands.

✱

Secrets stay masked

Sensitive-file scans show card numbers, IBANs and keys masked, and the results never leave your Mac.

⊘

No network, no tracking

No account, no analytics, no uploads. Photo comparison and text recognition run on-device.

FAQ

Questions, answered.

Is Glint really free?

Yes. Glint is completely free: no paid tier, no subscription, no cap on how much you can clean and no account. Download the DMG and use every feature.

Is it safe? What won't it delete?

Glint refuses to delete protected locations: system folders such as /System, /usr and the keychains, and your top-level folders such as Documents, Desktop, Pictures and ~/Library itself. Caches that apps rebuild on their own are deleted permanently; everything else goes to Quarantine first and can be restored for 7 days by default (you can change this in Settings).

Does Glint send my files or data anywhere?

No. Glint makes no network requests of its own: no analytics, no crash reporting, no account, no uploads. Scanning, photo comparison and text recognition all run on your Mac. It only opens something online when you click it yourself, such as a photo's location in Apple Maps. Details are in the privacy note.

Can I undo a clean?

Yes, for everything that went to Quarantine. Open Quarantine & History, select the items and restore them to where they were, until the retention period ends. Rebuildable caches are deleted for good, but apps recreate them when they need them.

Which Macs are supported?

Any Mac running macOS 14 Sonoma or later, with Apple Silicon or an Intel processor. There's one universal download for both.

Why does it ask for Full Disk Access?

macOS hides folders like Mail, Safari data and other apps' containers from every app until you allow it. Without Full Disk Access Glint still works, but it can't see those places, so some caches, browser data and sensitive files are missed. The access is used only to scan and clean on your Mac, and you can turn it off at any time in System Settings › Privacy & Security › Full Disk Access.

Why does it ask for an admin password, or for a helper approval in System Settings?

A few jobs need root: freeing RAM, flushing DNS, reindexing Spotlight, scanning a raw disk for File Recovery and moving admin-owned items to Quarantine. You can install Glint's small privileged helper in Settings and approve it once in System Settings › General › Login Items; after that these jobs run without a password prompt each time. The helper only accepts requests from Glint signed by the same developer, checks every request again and runs a fixed set of operations. If you skip it, Glint uses the standard macOS password prompt instead.

Is Glint signed and notarized?

Yes. Glint is signed with an Apple Developer ID and notarized by Apple, so it opens normally after you drag it into Applications.

Does it work while Docker or other apps are running?

Yes. Glint checks for running apps whose files aren't safe to delete while they're in use. While Docker Desktop runs, its VM files, logs and sockets are skipped and Glint tells you why; quit Docker and scan again to include them. Browser Privacy asks to quit an open browser before cleaning it.

Which languages does it speak?

Turkish and English. Glint follows your Mac's language, and you can switch at any time from Settings or the sidebar.
